# Projeto de Análise de Salários (SQL + Python)

## Objetivo
Este projeto tem como objetivo analisar os principais fatores que influenciam salários, utilizando SQL e Python.  
A análise busca entender o impacto de variáveis como experiência, nível educacional e trabalho remoto na remuneração.

---

## Tecnologias Utilizadas
- SQL (MySQL)
- Python (Pandas, Matplotlib)
- Jupyter Notebook
- Git & GitHub

---
## Análises Realizadas

### 1. Experiência vs Salário
- Avaliação do impacto dos anos de experiência na remuneração

### 2. Nível Educacional vs Salário
- Comparação dos salários médios por nível de escolaridade

### 3. Impacto do Trabalho Remoto
- Análise da diferença salarial entre trabalho remoto e presencial

### 4. Habilidades vs Salário
- Investigação da relação entre quantidade de habilidades e salário

---

## Principais Insights
- O salário tende a aumentar com a experiência
- Níveis educacionais mais altos estão associados a maiores salários
- O trabalho remoto apresenta diferenças relevantes na remuneração
- Existe correlação positiva entre número de habilidades e salário
